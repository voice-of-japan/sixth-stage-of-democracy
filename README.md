# The Sixth Stage of Democracy

## From Institutions to Protocols

A proposal for protocol-based democracy in the age of Artificial Intelligence.

### Author

Otoya Aizawa (Japan)

Former creator of the online escape game "Crimson Room" and founder of the Virtual Protest Protocol (VPP).

---

## Abstract

This project explores a possible sixth stage of democratic evolution.

Rather than asking:

**Who should rule?**

it asks:

**How can society be structured so that nobody can permanently become the ruler?**

The proposal introduces:

- Verifiable Presence Protocol (VPP)
- Verifiable Physical Autonomy Protocol (VPAP)
- Sortition-inspired civic assemblies
- Protocol-based governance in the age of AI
